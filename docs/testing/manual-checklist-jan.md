# Manuální checklist (Jan) — installer **0.1.0-prototype.4**

Krátký průchod s Windows buildem z [develop-latest](https://github.com/samwe20/Marginalia/releases/tag/develop-latest). Zaškrtávej v pořadí; u chyb přidej screenshot + kroky.

## Instalace a knihovna

- [ ] Nainstalovat nejnovější `Marginalia-0.1.0-prototype.4-…-setup.exe` z develop-latest
- [ ] První spuštění: vybrat složku knihovny (doporučeno podsložka v OneDrive)
- [ ] Přidat reálnou knihu PDF a EPUB (mimo demo)

## Čtení a zvýraznění

- [ ] PDF: zapnout **Zvýrazňovat**, uložit citaci, zkontrolovat `.md` ve složce knihy
- [ ] PDF: zavřít a znovu otevřít — zvýraznění na místě; změnit šířku okna — stále drží
- [ ] EPUB: zvýraznit, uložit, znovuotevřít; změnit velikost písma ve readeru (pokud dostupné)
- [ ] U citace doplnit poznámku s `[[název knihy]]` a otevřít odkaz

## Poznámky a Folio wikilinks

- [ ] **Poznámky** → nová poznámka, napsat `[[` a ověřit autocomplete
- [ ] Panel **Odkazuje sem** na poznámce, knize a citaci
- [ ] Klik na neexistující `[[…]]` → vytvoření poznámky

## Hledání a filtry

- [ ] **Hledat** (Ctrl+F): fráze z vlastní citace (FTS, ne jen demo)
- [ ] **Citace**: filtr kniha + štítek + text v gridu

## Demo režim

- [ ] Nastavení: načíst a odstranit ukázková data — uživatelské soubory beze změny

## Vzhled a klávesnice

- [ ] Přepnout Windows na tmavý režim — UI sleduje systém
- [ ] Reader: Esc skryje panel citací; Ctrl+O otevře dialog

## OneDrive a restart

- [ ] Na disku upravit text jedné citace `.md` v jiném editoru → restart Marginálie → změna vidět
- [ ] Úplný restart PC → cesta knihovny a obsah zachován

**Poznámka:** Položky označené v plánu jako „neimplementováno“ (FTS poznámek) zatím neočekávej.
